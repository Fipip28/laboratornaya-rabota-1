# 1.Постановка задачи
Мне необходимо разработать программу, которая получает на вход четыре различных целых числа и определяет среди
них число,которое при расположении всех чисел в порядке возрастания будет находиться на втором месте.
Для этого программа должна сравнить каждое из четырёх чисел с остальными. Искомое число должно быть больше
только одногочисла и меньше двух других чисел.
Например, пользователь вводит:
7 3 10 5
Если расположить эти числа по возрастанию, получится:
3 5 7 10
На втором месте находится число 5, поэтому программа должна вывести:
5
Таким образом, программа должна принимать четыре различных целых числа,
сравнивать их между собой и выводить второе по величине число, не выполняя непосредственную сортировку чисел.
