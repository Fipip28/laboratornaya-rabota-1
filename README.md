# 1.Постановка задачи
>Мне необходимо разработать программу, которая получает на вход четыре различных целых числа и определяет среди
>них число,которое при расположении всех чисел в порядке возрастания будет находиться на втором месте.
>Для этого программа должна сравнить каждое из четырёх чисел с остальными. Искомое число должно быть больше
>только одногочисла и меньше двух других чисел.
>Например, пользователь вводит:
>7 3 10 5
>Если расположить эти числа по возрастанию, получится:
>3 5 7 10
>На втором месте находится число 5, поэтому программа должна вывести:
>5
>Таким образом, программа должна принимать четыре различных целых числа,
>сравнивать их между собой и выводить второе по величине число, не выполняя непосредственную сортировку чисел.

# 2.Входные и выходные данные
>(Входные)На вход программы подаются 4 различных целых числа.
>Тип данных: int, так как в условии задачи указано, что числа являются целыми.
>Вещественные числа использовать не требуется.
>Количество: ровно 4 числа — n, i, p, l.
>Ограничение на количество: количество входных чисел фиксировано и равно 4,
>поэтому верхнего и нижнего ограничения на их количество нет — программа всегда получает именно четыре числа.
>Диапазон значений: в условии задачи конкретный диапазон чисел не указан.
>Поэтому при реализации на Java используется тип int. Диапазон типа int составляет:
>• минимальное значение: −2 147 483 648;
>• максимальное значение: 2 147 483 647.
>При этом введённые числа должны быть различными
>(выходные)На выход программа выводит одно целое число — второе по величине из четырёх введённых чисел.
>Тип данных: int, так как результатом является одно из исходных целых чисел.
>Вещественные числа или строки на выходе не используются.
>Количество: ровно 1 число. Программа не выводит остальные введённые числа и не выводит их в отсортированном виде.
>Диапазон значений: результатом является одно из четырёх входных чисел, поэтому он также находится в диапазоне типа >int:
>• минимальное значение: −2 147 483 648;
>• максимальное значение: 2 147 483 647.
# 3.Выбор структуры данных
>Для работы программы необходимо хранить четыре введённых целых числа.
>Так как количество чисел заранее известно и всегда равно четырём,
>использовать массив или другие сложные структуры данных нет необходимости.
>Каждое число будет храниться в отдельной переменной типа int:
>int n;
>int i;
>int p;
>int l;
>Тип int выбран потому, что по условию задачи на вход подаются целые числа.
>Кроме того, диапазона int достаточно для хранения допустимых значений.
>Ввод чисел осуществляется с помощью объекта Scanner:
>Scanner in = new Scanner(System.in);
>После ввода значения сохраняются в соответствующие переменные:
>int n = in.nextInt();
>int i = in.nextInt();
>int p = in.nextInt();
>int l = in.nextInt();
>Дополнительную переменную для хранения результата создавать не требуется.
>После определения второго по величине числа программа сразу выводит соответствующую переменную с помощью println().
>Таким образом, для решения задачи достаточно четырёх переменных типа int и объекта Scanner для считывания данных.
>Использование массива нецелесообразно, поскольку количество входных чисел фиксировано и равно четырём.
